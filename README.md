## 📌 About the Project

Student Study Planner is a frontend web application developed to help students manage their academic activities.

The application provides a simple dashboard where users can add subjects, create study tasks, mark tasks as completed, track their progress, and create a daily study schedule.

The project uses browser Local Storage to keep user data available even after refreshing the page.

## ✨ Features

- 📚 Add and manage subjects
- 📝 Create study tasks
- ✅ Mark tasks as completed
- ↩️ Undo completed tasks
- 🗑️ Delete tasks
- 📊 Automatic progress calculation
- 📈 Visual progress bar
- 📅 Create a daily study schedule
- 💾 Save data using Local Storage
- 📱 Responsive design
